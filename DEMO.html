🚀 Quick Start Commands:

# 1. Copy to web server
cp -r sales_dashboard /var/www/html/

# 2. Setup database
mysql < sales_dashboard/setup.sql

# 3. Import your data
php sales_dashboard/import_csv.php your_data.csv

# 4. Open in browser
http://localhost/sales_dashboard/

Works on Windows (XAMPP), Mac (MAMP), Linux, and all cloud platforms
